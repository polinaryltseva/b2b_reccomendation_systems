## Папка models\_boosting\_tree\_lr\_nb 
Выполнила Зайцева Арина

* eda\_analysis\_base\_models.ipynb: содержит реализацию предобработки данных
    * обработка названий регионов (приведение к единому виду)
    * анализ и выбор метода imputer для заполнения пропусков в различных признаках

* regions.ipynb: содержит реализацию обработки регионов при их неединственности для одного объекта
    * определение единственного региона, который должен остаться в ячейке с учетом наибольшей частоты встречаемости и близости

* base\_models.ipynb: содержит feature engineering и модели машинного обучения
    * генерация новых численных признаков
    * анализ и выбор метода imputer для заполнения пропусков в различных признаках
    * обработка временных признаков и генерация новых
    * отбор нужных признаков по матрице корреляций, анализ статистической значимости признаков
    * подбор способа шкалирования количественных признаков
    * обработка выбросов
    * решение проблемы временного сдвига и дисбаланса в данных
    * построение моделей машинного обучения (LogReg, Naive Bayes, Boosting, Decision Tree, Random Forest)

* visualization\_features.py: содержит реализацию функций отображения метрик

* tender\_recommender.py: содержит реализацию рекомендаций компаний для поставщиков
    * calculate\_company\_features(company\_data, historical\_data): вычисление признаков для компаний
    * prepare\_tender\_features(tender\_data, historical\_data): извлекает базовые характеристики тендера (регион, сфера и т.д.) и добавляет метрики из истории
    * get\_model\_components(model): извлекает ключевые части (препроцессор, классификатор) из объекта обученной модели
    * get\_candidate\_companies(tender\_data, companies\_db, historical\_data, top\_n): ищет подходящих потенциальных поставщиков для участия на основе совпадения региона и сферы деятельности
    * get\_recommendations(tender\_data, df, model, top\_n): прогоняет подготовленные данные через препроцессор модели, предсказывает вероятности успешного участия для каждой пары тендер-поставщик, ранжирует поставщиков по убыванию и возвращает топ-Т
    * evaluate\_recommendations(df, model, num\_tenders, k\_values, random\_seed, min\_suppliers): оценивает качество моделей на большом количестве тендеров и считает метрики качества

* model\_comparison\_rec\_syst.py: содержит функции для сравнения моделей при рекомендации поставщиков для тендеров
    * print\_comparison\_report(models\_results, model\_names): выводит отчет о сравнении моделей (ранги и значения метрик)
    * plot\_metrics\_comparison: создает визуальное представление производительности моделей

* second\_stage\_rec.ipynb: содержит реализацию отбора рекомендованных поставщиков на основе ранее обученных моделей для большого количества тендеров и сравнение результатов для разных моделей

## **Папка models_s_k_m_rec** 
Выполнила Полина Рыльцева

- `svm_knn_mlp.ipynb` содержит EDA, feature engeneering, базовые обученные модели (не на полных данных), работу с дисбалансом классов, оценку важности признаков

- `models_knn_mlp.ipynb` содержит обученные финальные модели KNN и MLP с оценкой важности признаков

- `models_svc_linear.ipynb` содержит обученную финальную модель LinearSVC c оценкой важности признаков

- `preprocessor.py` содержит скрипт для предобработки исходных данных в формат для подачи в модели (функция `def preprocess_tender_data(data: pd.DataFrame) -> pd.DataFrame`, а также несколько вспомогательных функций)

- `form_suppliers_df.py` содержит реализованный функционал ранжирования (второй этап) и оценки качества 
   - `def form_suppliers_df(data: pd.DataFrame) -> pd.DataFrame:` формирует пул поставщиков, агрегируя исторические данные 
   - `def filter_suppliers(suppliers_df, tender_info_df):` фильтрует кандидатов для нового тендера (эта функция не вызывается, если используется весь пул)
   - `def select_test_tenders(data, num_tenders: int = 5) -> List[pd.DataFrame]:` случайным образом выбирает тендеры для тестирования на основе определнных характеристик 
   - `def format_tender_info_dict(tender_df: pd.DataFrame) -> Dict[str, Any]:` преобразовывает данные о тендере, для которого ищутся потенциальные поставщики в удобный формат

- `second_stage_check.ipynb` содержит реализацию второго этапа: ранжирование потенциальных поставщиков для новых тендеров (с использованием `form_suppliers_df.py`) и оценкой качества моделей.    
    - Cодержит предобработку данных по компаниям (функции `def clean_geocomponent(text)`, `def clean_city_name(city_text)`, `def extract_region(components)`, `def extract_city(components, region_component=None)`)
    - Тут же реализован класс `SupplierRecommender` для расширения рекомендаций потенциальных поставщиков

- `supplier_recommender.ipynb` содержит реализацию рекомендательной системы в четырех конфигурациях и на основе Logistic Regression, Popularity и FMClassification с оценкой качества
